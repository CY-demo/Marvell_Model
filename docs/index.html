計算方法、假設限制與參考資料
  • 每條點對點光連線有兩個端點；本模型假設兩端均使用光模組，且每模組端點密度相同。
  • 多端點模組採彙總密度估計，未確認端點能否在同一設備上配對，也未做逐設備整數容量與相容性檢查。不可直接作為採購 BOM。
  • 百分比產生的結果為期望值，不擅自取整。DSP 是可能包含於模組的晶片，不等於模組或雷射；不同方案需確認其實際設計。
  • 不含 leaf-to-spine、scale-up、其他晶片、備品、庫存、供應商份額、ASP 或出貨排程。連線增加不等於算力或效能同比例增加。
  • GPU 數是 ratio 的分母，不用 TFLOPS 直接換算零件。GPU 為 0 時，比例未定義。
